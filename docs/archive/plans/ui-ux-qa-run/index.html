Known issues, not blocking

  • Kanban card indent on desktop. The drag grip is hidden until hover on mouse devices but still reserves its space, so card titles start with a small gap on the left.
  • Drag-and-drop tests can be flaky. Four drag tests passed on retry; the sidebar now starts expanded at 1440 px, which narrows the board and is a suspect. Recorded in docs/ISSUES.md.
  • Tasks list stops at 200 rows. The page says “Showing 200 of N” when more match; paging is deferred.
  • Drawer focus handling. Dialogs now trap and return focus; the side drawer does not, because it is deliberately non-modal. Needs a decision.
  • iTop screens not exercised. iTop is not connected on the dev stack, so the Tickets tab and Utilization data states are covered only by their e2e tests.
